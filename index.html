    Guía para el grupo

    Cómo insertar un video para que se reproduzca en la página

    Se usa un reproductor <iframe>. Solo cambia la dirección del video según la plataforma.

    YouTube

    1. Suban el video como Público o No listado y dejen activada la opción Permitir inserción.
    2. Copien el enlace: youtube.com/watch?v=ID o youtu.be/ID.
    3. Usen ese ID en la dirección youtube.com/embed/ID.
    <iframe src="https://www.youtube.com/embed/ID_DEL_VIDEO" title="Título del videotutorial" allowfullscreen> </iframe>

    Google Drive

    1. Compartan el archivo como Cualquier persona con el enlace · Lector.
    2. Copien el enlace: drive.google.com/file/d/ID/view.
    3. Cambien /view por /preview al final.
    <iframe src="https://drive.google.com/file/d/ID_DEL_ARCHIVO/preview" title="Título del videotutorial" allowfullscreen> </iframe>

    En esta página de ejemplo no hace falta escribir el iframe: basta con pegar el enlace normal en el campo url de la lista VIDEOS, al inicio del código, y la página hace la conversión. Si un video de Drive es privado, el visitante verá un aviso de permisos en lugar del video. Drive puede tardar unos minutos en procesar un video recién subido.

    ¿Dónde puedo publicar mi página web gratis?

    Para entregar el proyecto, la página debe estar publicada en internet con un enlace público que puedan compartir con el docente. Estas plataformas tienen opciones gratuitas.

    Recomendado para principiantes

    Netlify

    Arrastran la carpeta del proyecto a la página de Netlify Drop y en segundos obtienen un enlace público.

    Ventaja: es la opción más sencilla si trabajan únicamente con HTML. No necesitan instalar nada.

    app.netlify.com/drop Abrir Netlify ↗

    GitHub Pages

    Aloja gratuitamente páginas HTML, CSS y JavaScript guardadas en un repositorio de GitHub.

    Ventaja: aprenden a usar GitHub, una herramienta muy utilizada en Ingeniería en Sistemas.

    pages.github.com Abrir GitHub Pages ↗

    Vercel

    Publica proyectos web gratuitamente, incluidas páginas HTML estáticas.

    Ventaja: se conecta con GitHub y actualiza la página cada vez que guardan cambios.

    vercel.com Abrir Vercel ↗

    Cloudflare Pages

    Aloja páginas web estáticas gratuitamente y permite compartirlas mediante un enlace público.

    Ventaja: la página carga rápido desde cualquier lugar gracias a la red de Cloudflare.

    pages.cloudflare.com Abrir Cloudflare Pages ↗

    Puedes utilizar cualquiera de estas plataformas u otra que prefieras. Lo importante es que tu página web esté publicada, funcione correctamente y pueda consultarse mediante un enlace público. Antes de entregar tu proyecto, comprueba que los videotutoriales se reproduzcan directamente dentro de la página.
